# Expression By Akhil

Personal essays and memoirs by Akhilendra Verma. Built with [Hugo](https://gohugo.io) and hosted free on GitHub Pages.

**Live site:** https://akhilendraverma.github.io/

## How it works
- Posts live in `content/posts/` as Markdown files.
- The site auto-builds and deploys on every push via GitHub Actions (`.github/workflows/hugo.yml`).
- No local Hugo install needed to publish — just edit and push.

## Add a new post
Create a file in `content/posts/`, e.g. `2026-09-01-my-title.md`:

```
---
title: "My Title"
date: 2026-09-01T10:00:00
draft: false
image: "https://url-to-a-thumbnail.jpg"
---

Your writing here…
```

Commit and push — the site updates automatically in a minute or two.
